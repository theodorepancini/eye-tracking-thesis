# eye-tracking-thesis
Software pipeline for near real-time eye tracking with MRI-compatible cameras at Örebro University Hospital (USÖ). Turns raw binocular video into timestamped pupil size and gaze measurements with confidence scores, for research in e.g. neuroscience and ophthalmology. 

The project is made as a replication study based on Lu et al., 2026: https://github.com/xuepx/cgf_pupil_detector at commit 0010408. 

the LPW data-set used in the original study can be found at: https://www.mpi-inf.mpg.de/departments/computer-vision-and-machine-learning/research/gaze-based-human-computer-interaction/labelled-pupils-in-the-wild-lpw
